# 🧠📱 ReviewInsightX: AI-Assisted App Review Summarization & Strategic Feedback Extraction

**ReviewInsightX** is an AI-powered tool that collects, processes, and analyzes mobile app user reviews from the **Google Play Store**, turning raw qualitative feedback into actionable product insights and strategic recommendations. The output is saved as both **text** and **PDF** files, making it easy to share or present findings with stakeholders.

⚙️ **How Does It Work?**

1. **Fetch Reviews**
   Uses the `google-play-scraper` to collect recent user reviews from a selected app on the Google Play Store.

2. **Preprocess Text**
   Cleans and filters the reviews (lowercasing, removing punctuation, trimming spaces).

3. **Analyze Using LLM**
   Sends preprocessed reviews to a large language model via **Hugging Face** API using OpenAI-compatible calls.

4. **Summarize Findings**
   Generates a structured report in Markdown format, including:

   * 🧠 Key Insights Table
   * 💡 Strategic Suggestions

5. **Export**
   Converts the analysis to both `.txt` and `.pdf` formats using Markdown + WeasyPrint.

🛠️ **Technologies Used**

| Technology                                     | Purpose                                                       |
| ---------------------------------------------- | ------------------------------------------------------------- |
| `google-play-scraper`                          | Fetches real user reviews from the Google Play Store          |
| `re`, `csv`, `datetime`, `collections.Counter` | Text cleaning, date filtering, and data handling              |
| `openai` (via Hugging Face)                    | Sends structured prompts to a large language model            |
| `markdown`, `weasyprint`                       | Converts Markdown to HTML, then exports to PDF                |
| `google.colab.userdata`                        | Securely retrieves API tokens inside Google Colab environment |

---

🤖 **AI Model Used**

* **GPT-OSS-20B**
  An open-source large language model hosted on **Hugging Face**, used to generate insightful summaries and product suggestions from cleaned review data.
